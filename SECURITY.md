# Security Policy

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/global-suite/global-service-studio/security/advisories/new)).

Please include:

- What the problem is and what an attacker could do with it.
- Steps to reproduce it, or a proof of concept.
- The app version or commit, and your macOS version.

You will get an acknowledgement, and the fix and disclosure will be coordinated with you.

## Supported versions

The project is in pre-alpha. Only the latest release, once there is one, receives security fixes.

## In scope

- The application and its local remote-control API.
- File import: songs, presentations and media opened by the app.
- The update mechanism and the release pipeline.

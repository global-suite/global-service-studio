# Feature map

Every feature the project intends to build, grouped by area, with the [roadmap](roadmap.md) phase it belongs to.

The list was drawn up by studying what operators expect from established presentation software, ProPresenter in particular, and deciding what a free tool for churches needs first. It is a plan, not a promise of parity, and nothing here is built until the roadmap says so. Global Service Studio is not affiliated with Renewed Vision.

Phase **–** means the feature is deliberately out of scope for now.

## Import and integrations

| Feature | What it does | Phase |
|---|---|---|
| Plain text import | Turn a text file into a song | 1 |
| OpenLyrics import and export | Exchange songs in the open standard | 1 |
| ChordPro and OpenSong import | Bring in songs from other free tools | 2 |
| Import from other presentation software | Migrate an existing library | 2 |
| Slide deck import | Bring in a sermon slide deck | 2 |
| CCLI number and song credits | Show license and copyright details on slides | 2 |
| Song usage log | Export what was sung, for license reporting | 2 |
| Service planning integration | Pull the order of service from a planning tool | 5 |
| Commercial song catalogue integration | Search and import from inside the app | – |
| Cloud sync | Sync a library through a hosted service | – |

A commercial catalogue integration is out of scope because no partner program is currently open to new integrators. The [song import strategy](song-import.md) explains what is done instead. A library is a folder of plain files, so it can already be synced with any file-sync tool.
